# Project Charter

## Vision

Build a production-grade Enterprise AI News Intelligence Platform that ingests, processes, enriches, and serves global event intelligence using modern Data Engineering and AI technologies.

The platform will evolve from a scalable lakehouse into an AI-native analytics platform capable of supporting both traditional Business Intelligence and Retrieval-Augmented Generation (RAG) applications.

---

## Business Goals

- Build a production-grade Data Engineering portfolio project.
- Process large-scale global event data using distributed computing.
- Demonstrate modern lakehouse architecture and engineering best practices.
- Provide trusted datasets for business analytics.
- Establish a governed data foundation for future AI applications.
- Showcase enterprise architecture suitable for Data Engineering interviews.

---

## Objectives

- Build an end-to-end data platform using Python, Apache Spark, Delta Lake, AWS S3, Airflow, Snowflake, and Power BI.
- Process historical and incremental GDELT datasets.
- Implement the Medallion Architecture (Bronze, Silver, Gold).
- Create business-ready fact and dimension models.
- Integrate AI capabilities such as metadata generation, embeddings, semantic search, and a RAG-based business assistant.
- Follow production engineering practices including version control, documentation, testing, monitoring, and CI/CD.

---

## Scope

The project includes:

- Data ingestion from GDELT
- Workflow orchestration
- Lakehouse architecture
- Distributed data processing
- Data warehouse modeling
- Business Intelligence dashboards
- AI enrichment
- Embedding generation
- Vector search
- RAG-based business assistant
- Engineering documentation
- CI/CD and monitoring

---

## Non-Goals

This project is not intended to:

- Replace a production news platform.
- Build a real-time streaming system in the initial releases.
- Train custom machine learning models.
- Perform advanced NLP research.
- Build a consumer-facing application.
- Cover every cloud service available.

The focus is to demonstrate production-grade Data Engineering with practical AI integration.

---

## Success Metrics

The project will be considered successful if it:

- Processes more than 50 GB of data.
- Implements a complete Medallion Architecture.
- Supports incremental data ingestion.
- Delivers business-ready analytics through Snowflake and Power BI.
- Successfully integrates AI capabilities such as embeddings and RAG.
- Demonstrates production engineering practices.
- Serves as a flagship GitHub portfolio project.
- Is explainable end-to-end during a Data Engineering interview.
